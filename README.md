# prj01 — สัตว์เลี้ยงขี้เล่น

หน้าเว็บแอนิเมชันสัตว์เลี้ยงหน้ายิ้มแป้น เปิด `index.html` ในเบราว์เซอร์ได้ทันที (ไฟล์เดียว ไม่ต้อง build)

- เลือกสัตว์เลี้ยงจากแถบด้านล่าง: แมวลายวัวสีฟ้า, แมวส้ม, แมวสลิด, แมวสามสี, หมาบางแก้ว, ไซบีเรียน, ชิวาวา, ชิสุ, ปอม, โกลเด้น (ทุกตัวทำได้ทุกท่า และจำตัวที่เลือกไว้)
- ให้อาหาร: กดปลา เนื้อ ขนม หรือนม จะมีชามอาหารตกลงมา น้องวิ่งไปกินงั่มๆ แล้วหลอดความอิ่มเพิ่มขึ้น (แมวชอบปลากับนม หมาชอบเนื้อกับขนม) ถ้าความอิ่มต่ำน้องจะบ่นหิว
- ของเล่น: ลูกบอล ไหมพรม เป็ดบีบ (กลิ้งเด้งได้ ลากโยนเองได้ น้องจะวิ่งไปเตะ ตะครุบ หรือกอดบีบ) และไม้ขนนกที่ลอยตามเมาส์หรือนิ้ว น้องจะวิ่งไล่และกระโดดตะครุบ กดปุ่มเดิมซ้ำเพื่อเก็บของเล่น
- แตะที่น้อง: ทักทาย กระโดด ตื่นเต้น หมุนตัว ตีลังกา เต้น ส่งหัวใจ จ๊ะเอ๋ หัวเราะจั๊กจี้ ตะครุบ วิ่งซูม
- แตะรัวๆ 6 ครั้ง: ตื่นเต้นสุดๆ พร้อมพลุกระดาษ
- กดค้างแล้วลาก: ยกแมวลอยไปไหนก็ได้ ขาดิ้น ตัวแกว่งตามแรงลาก ปล่อยแล้วตกลงพื้น (ปล่อยจากสูงจะมึนหัว)
- แตะพื้น: แมววิ่งมาหา
- ไม่มีใครเล่นด้วย: 12 วินาทีเริ่มเบื่อ, 22 วินาทีง่วง หาว สัปหงก, 32 วินาทีหลับ (มี Zzz และฟองจมูก)
- ปลุกตอนง่วงหรือหลับ: งัวเงีย ขยี้ตา บิดขี้เกียจ แล้วค่อยตื่น
